Jobly, sur votre ordinateur.

Vos stages et alternances tech en France. Installez l’application, ouvrez-la depuis son icône et retrouvez votre espace habituel.

Télécharger → dézipper → ouvrir l’installateur → lancer Jobly.

Ouvrir le dossier des installateurs · Voir les fichiers réellement construits et testés

Sur macOS

  1. Dans installateurs, ouvrez le fichier .dmg adapté à votre Mac : arm64 pour Apple Silicon, x64 pour Intel.
  2. Glissez Jobly dans Applications.
  3. Éjectez le disque d’installation.
  4. Lancez Jobly depuis Applications ou Launchpad.
  5. Créez votre compte local ou importez votre sauvegarde.

Un build local sans signature Apple n’est pas une distribution publique notarisée. Si le système refuse l’ouverture, utilisez la version signée de l’éditeur. Ne désactivez pas les protections de macOS.

Sur Windows

  1. Vérifiez qu’un installateur win-x64.exe est présent dans le dossier des installateurs.
  2. Double-cliquez sur le fichier .exe.
  3. Suivez l’assistant d’installation.
  4. Ouvrez Jobly depuis le menu Démarrer ou le Bureau.
  5. Créez votre compte local ou importez votre sauvegarde.

Si aucun EXE n’est fourni, la livraison Windows est encore à construire sur Windows. Le dépôt comprend cette automatisation. Aucun lien de téléchargement fictif n’est proposé.

Tout démarre avec l’application.

Aucun terminal, Docker ou environnement de développement à installer pour utiliser la distribution. Le backend de production et la base locale sont inclus ; ils s’arrêtent à la fermeture. Les données et paramètres restent sur votre ordinateur.

Internet est nécessaire pour les nouvelles offres et les candidatures. Les données déjà collectées restent consultables hors connexion. La collecte fonctionne à l’ouverture puis toutes les deux heures tant que Jobly reste ouvert. Les sites sources peuvent bloquer ou limiter l’accès : leur état est visible dans l’application.

Au premier lancement

Créez un compte local avec votre nom, votre email et un mot de passe. Aucun secret serveur ou abonnement n’est demandé. La version bureau conserve les CV sur disque. Les confirmations, réinitialisations et alertes arrivent dans Fichier → Bureau et messages locaux ; elles ne sont pas envoyées à l’extérieur.

Pour transférer vos données, utilisez Sauvegarder puis Importer une sauvegarde. Les archives contiennent des informations personnelles et ne sont pas chiffrées : conservez-les en lieu sûr.

Un problème ?

La préparation ne se termine pas

Fermez puis relancez Jobly et vérifiez l’espace disque. Le menu Aide donne accès au journal jobly.log. Ne supprimez pas le dossier de données pour résoudre un blocage.

Je ne vois pas encore d’offres

Connectez-vous à Internet, puis choisissez Fichier → Actualiser les offres. Les résultats arrivent progressivement. Consultez les erreurs et les résultats par source dans l’écran Bureau. La première collecte peut prendre plusieurs dizaines de minutes.

Je n’ai reçu aucun email

Ouvrez Fichier → Bureau et messages locaux. Les emails sont une boîte locale dans cette édition, pas un envoi vers votre messagerie.

Où sont mes données ?

macOS : ~/Library/Application Support/Jobly/. Windows : %APPDATA%\Jobly\. Le bouton Dossier de données ouvre directement cet emplacement.

Comment vérifier les fichiers ?

Le fichier SHA256SUMS.txt contient les empreintes des installateurs fournis. Le guide détaillé explique les commandes facultatives de contrôle. Un document Markdown est une documentation, pas un programme d’installation.

Code source et compilation

La compilation s’adresse aux développeurs et se fait depuis le dépôt, avec Node et les outils du système cible. Elle est distincte de l’installation ci-dessus. Le README fournit les commandes. Aucun outil de compilation n’est requis pour l’utilisation quotidienne.
