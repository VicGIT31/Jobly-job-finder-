Ce guide explique l’installation : l’ouvrir ne lance aucun programme d’installation. Seuls les fichiers réellement présents dans le dossier installateurs sont disponibles.

Sur macOS

  1. Dans « À propos de ce Mac », vérifiez Apple Silicon (arm64) ou Intel (x64).
  2. Ouvrez le .dmg correspondant dans le dossier des installateurs.
  3. Glissez Jobly dans Applications.
  4. Éjectez le disque, puis lancez Applications → Jobly.

Sur Windows

  1. Utilisez Windows 10/11 x64.
  2. Ouvrez l’installateur .exe présent dans le dossier.
  3. Suivez l’assistant et choisissez vos raccourcis.
  4. Lancez Jobly depuis Démarrer ou son icône de bureau.

Vos dix premières minutes

  1. Choisissez Commerce & marketing ou Auxiliaires vétérinaires.
  2. Gardez Toulouse à 30 km, ou saisissez une commune et un rayon. « Toute la France » élargit explicitement la recherche.
  3. Consultez les premiers lots pendant l’actualisation. Affinez les contrats, l’expérience et le télétravail.
  4. Enregistrez un favori et une recherche. Postuler ouvre la véritable annonce dans votre navigateur.

Internet est nécessaire à la collecte, aux candidatures, à certains logos et au géocodage distant. Le catalogue déjà collecté et vos données restent locaux. La couverture varie selon les sources ; une offre récemment vérifiée n’est pas nécessairement récemment publiée.

Mettre à jour sans perdre ses données

Quittez Jobly et remplacez uniquement l’application avec le nouvel installateur. Ne supprimez pas son dossier de données. Une sauvegarde privée précède la migration des profils 0.2.x. Les favoris, recherches, notes et candidatures sont regroupés dans votre espace personnel.

Aucun Node.js, Docker, terminal ou serveur à démarrer n’est nécessaire au quotidien. La compilation depuis les sources est une procédure distincte réservée aux développeurs.

Un problème ?

Pas d’offres ou actualisation interrompue

Consultez « Actualisation & données », vérifiez Internet et les critères, puis relancez l’actualisation. Élargissez volontairement la zone si nécessaire. Les sources inaccessibles ne bloquent pas les autres. Pour une nouvelle ville, cliquez Actualiser après l’avoir saisie.

Éditeur inconnu ou installation bloquée

Les paquets sans certificats restent non signés par un éditeur reconnu et les DMG non notarisés. Vérifiez la provenance et les empreintes SHA-256. Utilisez une version signée lorsqu’elle est fournie si les protections refusent le paquet. Ne désactivez pas globalement Gatekeeper, SmartScreen ou l’antivirus.

Données, CV ou recherche

« Actualisation & données » propose sauvegarde, restauration et réparation de l’index. Un CV absent de la sauvegarde d’origine doit être réimporté. Le menu Aide donne accès au journal de diagnostic.

Installer avec une seule ligne

Téléchargez d’abord le ZIP de livraison dans Téléchargements, sans le renommer. Utilisez votre navigateur connecté au dépôt privé. Ensuite, copiez la ligne de votre système : elle vérifie l’intégrité, installe Jobly et la lance. Aucun jeton ni clé API nécessaire.

macOS · Terminal

/bin/bash -c 'a=x64; [ "$(/usr/sbin/sysctl -n hw.optional.arm64 2>/dev/null)" = 1 ] && a=arm64; z="$HOME/Downloads/Jobly-0.3.0-darwin-$a.zip"; [ -f "$z" ] || { printf "%s\n" "Téléchargez le ZIP Jobly 0.3.0 pour votre Mac dans Téléchargements, puis réessayez."; exit 1; }; d=$(mktemp -d); /usr/bin/ditto -x -k "$z" "$d" && /bin/bash "$d/Jobly-0.3.0-darwin-$a/INSTALLER-macOS.sh"; r=$?; rm -rf "$d"; exit "$r"'

Windows x64 · PowerShell

$zip=Join-Path $HOME 'Downloads\Jobly-0.3.0-win32-x64.zip'; if(!(Test-Path -LiteralPath $zip)){throw 'Telechargez le ZIP Windows Jobly 0.3.0 dans Telechargements puis reessayez.'}; $work=Join-Path ([IO.Path]::GetTempPath()) ('Jobly-'+[guid]::NewGuid()); try { Expand-Archive -LiteralPath $zip -DestinationPath $work; $root=Join-Path $work 'Jobly-0.3.0-win32-x64'; $name='Jobly-0.3.0-win-x64.exe'; $setup=Join-Path $root ('installateurs\'+$name); $lines=@(Get-Content -LiteralPath (Join-Path $root 'SHA256SUMS.txt') | Where-Object { $_.EndsWith('  installateurs/'+$name) }); if($lines.Count -ne 1){throw 'Empreinte absente ou ambigue.'}; $want=($lines[0] -split '\s+')[0]; if($want -notmatch '^[a-fA-F0-9]{64}$' -or (Get-FileHash -LiteralPath $setup -Algorithm SHA256).Hash -ine $want){throw 'Integrite incorrecte : installation annulee.'}; @(Get-Process -Name Jobly -ErrorAction SilentlyContinue) | Where-Object { $_.MainWindowHandle -ne 0 } | ForEach-Object { [void]$_.CloseMainWindow(); if(!$_.WaitForExit(15000)){throw 'Fermez Jobly puis relancez la commande.'} }; $dest=if($env:JOBLY_INSTALL_DIR){$env:JOBLY_INSTALL_DIR}else{Join-Path $env:LOCALAPPDATA 'Programs\Jobly'}; $p=Start-Process -FilePath $setup -ArgumentList @('/S',('/D='+$dest)) -Wait -PassThru; if($p.ExitCode -ne 0){throw ('Installation interrompue : '+$p.ExitCode)}; if($env:JOBLY_NO_LAUNCH -ne '1'){Start-Process -FilePath (Join-Path $dest 'Jobly.exe')}; Write-Host ('Jobly installee dans '+$dest) } finally { if(Test-Path -LiteralPath $work){Remove-Item -LiteralPath $work -Recurse -Force} }

Ouvrez Terminal sur macOS ou PowerShell sur Windows, collez la ligne puis validez avec Entrée. Les protections du système restent actives ; un paquet non signé peut être bloqué. Vos données restent dans leur dossier habituel. Si le ZIP est enregistré ailleurs, déplacez-le dans Téléchargements. Aucun terminal nécessaire pour l’usage quotidien.
