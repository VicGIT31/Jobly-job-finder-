# Jobly 0.6.2

- Profil local par installation. Le choix de l’assistant reste modifiable depuis le menu Assistant.
- GitHub Copilot affiche les modèles autorisés via votre propre compte GitHub. Ollama affiche les modèles conversationnels installés sur votre ordinateur.
- Jobly collecte les offres sans clé API. Le classement local fonctionne aussi lorsque l’assistant est désactivé ou indisponible.
- Category Manager est disponible dans la recherche et les filtres. La collecte couvre aussi les sources accessibles outre-mer.
- Les favoris, candidatures, recherches et fichiers des versions précédentes restent compatibles.
